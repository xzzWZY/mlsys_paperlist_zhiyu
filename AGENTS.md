# Paperlist repository

Monthly submissions live in `entries/First_Last/YYYY-MM.yaml`. Configuration is in `config/paperlist.json`. The homepage and `catalog/` are generated by `scripts/index.py`.

When asked to classify paper topics, follow [docs/classify-topics.md](docs/classify-topics.md). Classification is member-triggered; do not run it merely because you opened the repository. Preserve existing tags unless retagging was requested.

For paper submissions and classification, use a working branch and a reviewed pull request. Do not push directly to `main`. Run `scripts/validate.py` and the unittest suite before proposing changes. Avoid committing generated indexes or the first-added ledger in submission/classification PRs; the index workflow updates them after merge.
