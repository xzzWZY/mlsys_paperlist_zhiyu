# Paperlist repository

Submissions live in `entries/First_Last/YYYY-MM.yaml`; configuration lives in `config/paperlist.json`. The homepage and `catalog/` are generated by `scripts/index.py`.

All members share one weekly branch (`submissions/YYYY-MM-DD_to_YYYY-MM-DD`) and one weekly PR to `main`. Monthly YAML files continue across weeks. Never push submission or classification work directly to `main` or create separate member/classification PRs.

When asked to classify topics or prepare the weekly PR, follow `docs/classify-topics.md`. This is member-triggered, not automatic. Preserve existing tags unless corrections were requested.

Before opening/updating a weekly PR, run `scripts/validate.py --require-topics` and the unittest suite. Missing topics block the PR. Do not commit generated indexes or `data/added_at.json` in weekly PRs; the index workflow updates them after merge.
